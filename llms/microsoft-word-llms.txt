# Microsoft Word

> APIs for Microsoft Word document creation, manipulation, and automation across Microsoft 365 cloud services, Office Add-ins, SharePoint, and Open XML document processing. Cloud operations run through the Microsoft Graph v1.0 endpoint and authenticate with OAuth 2.0 via the Microsoft Identity Platform.

This llms.txt is generated by API Evangelist from the apis.yml catalog and the artifacts in this repository (Microsoft does not publish an llms.txt on learn.microsoft.com — /llms.txt returned 404).

## APIs

- [Microsoft Graph Word API](https://learn.microsoft.com/en-us/graph/api/overview?view=graph-rest-1.0): REST API for Word documents in Microsoft 365 / OneDrive via Microsoft Graph (base https://graph.microsoft.com/v1.0).
- [Office JavaScript API for Word](https://learn.microsoft.com/en-us/javascript/api/word): Client-side JavaScript API for building Word add-ins.
- [Word Automation Services (SharePoint)](https://learn.microsoft.com/en-us/sharepoint/dev/general-development/word-automation-services-in-sharepoint): Server-side document conversion for SharePoint.
- [Open XML SDK for Word](https://learn.microsoft.com/en-us/office/open-xml/open-xml-sdk): .NET library for ECMA-376 Open XML document manipulation.
